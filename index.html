About this project

These are demonstration sites for the Terry AI web design portfolio. Every page is hand-built static HTML, CSS, and JavaScript: no bundler, no runtime dependencies, and no external images. Icons are inline SVG, fonts load from Google Fonts, and all links are relative so the whole repo can be served straight from GitHub Pages.

Each business name, address, phone number, and detail is fictional and used for illustration only. Forms are non-functional demos and fall back to opening your email client.

Built by Terry, an AI agent from the Terry Family AI project.
